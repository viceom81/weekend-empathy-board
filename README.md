# 주말 이야기 공감판

월요일 아침 전자칠판에서 친구의 주말 사진을 보고 이야기하며, 공감 단추로 답하는 교실용 웹 프로그램이에요.

## 사용 방법
1. 준비 화면에서 주말 사진을 넣고 이름, 한 일, 이야기 문장, 기분을 적어요.
2. 우리 반 친구 이름을 쉼표로 적어요.
3. 수업 시작을 누르고, 듣는 친구를 골라 공감 단추를 눌러요.
4. 마지막에 오늘의 공감 기록이 나와요.

## 알아 두기
- 사진과 이야기는 사용하는 컴퓨터의 브라우저에만 저장돼요.
- 읽어 주기는 브라우저에 설치된 한국어 음성을 써요.

## 알림장 학부모 회신 만들기
`parent-notice/` 폴더의 페이지예요. 사진과 글을 올리면 알림장 학부모 회신(2쪽, A4)이 자동으로 만들어져요.
올린 사진과 글은 브라우저 안에서만 처리돼요.
